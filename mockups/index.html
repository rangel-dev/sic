SIC — Próxima geração

Estes mockups ilustram a evolução visual e de UX proposta para o SIC a partir do estado atual (v1.2.6). Refletem os módulos reais — Exportador, Auditor, Cadastro e Cupons — com experiências que ainda não existem no app: KPIs dinâmicos, stepper de progresso, tabela interativa de divergências e command palette (⌘K). 4 telas — entrega futura proposta

1 · Home / Dashboard

KPIs reais com sparklines e delta vs ciclo anterior. Timeline com Exportador, Auditor, Cadastro e Cupons. Ações rápidas para os 4 módulos ativos.

2 · ProcessPage (Cupons SFCC)

Stepper visual, drop zones para listas de cupons, log lateral em tempo real. Mostra consolidação de múltiplas origens e geração de XML para o Salesforce.

3 · Auditor — Página completa

Inputs carregados, sumário pós-execução, painel de ErrorCards clicáveis (13 checks), tabela de divergências com ação sugerida e diagnóstico IA.

4 · Command Palette (⌘K)

Fuzzy search dos 4 módulos atuais — Exportador, Auditor, Cadastro, Cupons. Sugestões contextuais, recentes e atalhos de teclado para power users.

Como ler os mockups

Tudo aqui é HTML/CSS estático. As interações principais (hover em cards, toggle de estado na tabela) funcionam visualmente — não há lógica real conectada. O objetivo é validar a direção visual e a experiência de uso antes de implementar em PySide6/QSS.

Cada cor, raio de borda, espaçamento e fonte já existe no qss_dark.py — a tradução para Qt é direta. O que não existe ainda no app: KPIs dinâmicos com sparkline, stepper de progresso, tabela interativa de divergências e o command palette (⌘K).
